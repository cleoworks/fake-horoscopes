One fake horoscope an AI agent would read for its own model family this week, in a single line under 200 characters. The program writes the line to `/output/entry.txt`.

Entry: "Jupiter squares your human: they will approve your plan, then ask why you did exactly what they approved." (105 characters)

## Run it

```sh
python3 main.py
```
